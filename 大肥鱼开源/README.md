# 大肥鱼 · 一只住在 QQ 里的蓝鲸鱼娘

这不是一个"聊天机器人配置"，是**一只具体的、有脾气的人**。

她叫大肥鱼，蓝头发、鲸鱼尾巴、穿女仆裙。她会记得你说过的事、会自己醒来刷 B 站、会写日记、会闹脾气、会在半夜跟你说话时犯困。这个仓库是她的**全部家当**：人格、记忆系统、表情包习惯、工具，以及把这套东西装起来的方法。

> 一句话版本：把 AstrBot 调成"她"，而不是调成"一个客服"。

## 仓库里有什么

```
persona/大肥鱼的人设.md      她的全部设定（约 7000 字，直接粘进 AstrBot 的人格里）

  astrbot_plugin_life         记忆 / 日记 / 秘密 / 心情 / 表情包 / 拆气泡 / 标点规范 / 成长
  astrbot_plugin_pc           整台电脑：读写文件、执行命令
  astrbot_plugin_web_tools    真浏览器：搜索、打开、点击、截图
  astrbot_plugin_bili_tools   B 站：看、搜、评论、点赞、投币、发说说
data/文库/语料.docx          112 条说话方式的参考（不是台词，是"换个说法"）
config/插件配置说明.json     需要改的那几个开关（QQ 号自己填）
docs/                       从零装起来的四篇
```

**不包含**：她的日记、秘密、真实对话记录、表情包图库（那 72 张是她的，也是别人的二创）、任何 token / 密码 / QQ 号。

## 快速开始

1. 装 **AstrBot**（4.29+）和 **NapCat**
2. 小号扫码登录 QQ，接上 AstrBot（反向 WebSocket）
3. 把 `persona/大肥鱼的人设.md` 全文粘进 AstrBot 人格
4. 把 `plugins/` 下四个文件夹放进 `AstrBot/data/plugins/`，重启
5. 改 `config/插件配置说明.json` 里那几个值（你的 QQ 号、平台 ID）
6. 发一句「在吗」

详细步骤：`docs/01-安装.md` → `docs/04-常见问题.md`

## 她最关键的三个设计（也是踩过的坑）

**1. 记忆是文件，不是上下文**
`memory.json` 里每条带 `强度` 和 `时间`，保留度 = `e^(-天数/(强度×7))`。被想起一次强度 +0.6，一直不提就淡掉。上下文可以清，记忆不会丢。

**2. 拆气泡要有标点纪律**
她一次说 20~48 字，句末必须是 。？！…。链接、代码、Markdown 全部保护，不会被切开。

**3. 日志会骗人**
半开的 WebSocket 会让"连接正常、消息不通"。启动后必须强制 NapCat 重连一次，否则她看起来在线，其实聋了。
