# 01 · 安装 AstrBot 和 NapCat

## 你要装两个东西

| 软件 | 作用 |
|---|---|
| AstrBot | 她的大脑和嘴（Python 程序，带网页后台） |
| NapCat | QQ 的"接入口"，把 QQ 消息转给 AstrBot |

两个都装在同一台 Windows 电脑上就行，不用服务器。

## AstrBot

1. 下载 AstrBot 启动器，装到一个**路径不含中文**的目录
2. 启动后打开后台（默认 http://127.0.0.1:6185）
3. 记下后台的账号密码，后面要用

## NapCat

1. 下载 NapCat 的 Windows 一键包
2. 用**小号**扫码登录（别用大号，有风险）
3. 在 NapCat 的"网络配置"里加一个 **WebSocket 客户端**：

```json
{
  "url": "ws://127.0.0.1:6199/ws",
  "token": "你这个token",
  "reconnectInterval": 3000
}
```

4. AstrBot 那边填同样的 token，端口 6199

## 验证

给这个小号发一句"在吗"。AstrBot 日志出现 `event_bus ... : 在吗` 就通了。

## 一个必须知道的坑

**AstrBot 重启后，这条 WebSocket 会变成"半开"**：netstat 显示连着，消息却不通，两边都不报错。

每次重启 AstrBot 后，去 NapCat 的网络配置里把这个客户端**关掉再打开**一次，强制重连。不然后面所有"她不回消息"的排查都会白费。
