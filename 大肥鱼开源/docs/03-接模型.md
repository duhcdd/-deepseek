# 03 · 接 DeepSeek（或任何 OpenAI 兼容模型）

## AstrBot 里加 Provider

后台 → 服务提供商 → 新增 → 选 OpenAI 兼容，填：

```
API Base: https://api.deepseek.com/v1
API Key : sk-你的key
模型     : deepseek-chat（或 deepseek-flash）
```

保存后把它设为**默认对话模型**。

## 一个实际问题：成本

她一次回复通常 20~50 字，但每轮会带上人格（7000 字）+ 记忆（6~10 条）+ 语料参考。
**大头是人设，不是对话**。

降成本的办法（都在这套配置里）：

1. 人格按需精简 —— 砍掉你不在乎的段落
2. 记忆只注入最该被想起的 6 条（`_recent_memory_block(n=6)`）
3. 夜里定时 `/reset` 清上下文，长期记忆走文件，不占 token
4. 情绪/剧情类的玩法用便宜模型，正经问答再切贵的

## 上下文会爆

单会话几百万字符之后，模型开始返回空文本——表现就是"已读不回"。
插件里有夜间自动清理，一定要开。

## 换模型之后

她的说话方式会变（不同模型的措辞习惯不同）。
如果变得不像她了，先看人格提示词的【示例（照这个语气）】那一段，把示例换成她真实说过的话——比重写一遍设定管用。
