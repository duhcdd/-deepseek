# 02 · 装插件

四个插件都是自己写的，不是市场件，所以直接拷文件夹。

## 放哪

```
AstrBot\data\plugins\
  astrbot_plugin_life\
  astrbot_plugin_pc\
  astrbot_plugin_web_tools\
  astrbot_plugin_bili_tools\
```

放好重启 AstrBot。日志里应该出现一批：

```
Added llm tool: life_status
Added llm tool: remember
Added llm tool: pc_run
Added llm tool: web_search
Added llm tool: bili_hot
...
```

## 她会多出什么

| 插件 | 工具 |
|---|---|
| life | life_status / life_mood / life_diary / life_secret / remember / recall / send_sticker / life_growth |
| pc | pc_list / pc_read / pc_write / pc_mkdir / pc_delete / pc_download / pc_run |
| web_tools | web_search / web_open / web_click / web_type / web_scroll / web_screenshot |
| bili_tools | bili_hot / bili_search / bili_video / bili_like / bili_coin / bili_reply / qzone_post |

## 三个容易踩的依赖

1. `python-docx`（写日记/记忆用）—— 没装她会说"写不了 Word"
2. `playwright` + 浏览器（web_tools 用）
3. `pillow`（表情包和图片处理）

在 AstrBot 的 venv 里装：

```powershell
& "实例\venv\Scripts\python.exe" -m pip install python-docx playwright pillow -i https://mirrors.aliyun.com/pypi/simple/
& "实例\venv\Scripts\python.exe" -m playwright install msedge
```
