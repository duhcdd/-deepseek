# 04 · 常见问题

## 她不回消息，但显示在线

按这个顺序查：

1. **消息到了 AstrBot 吗** —— 日志搜 `event_bus`。没有 → NapCat 那侧卡了，重启 NapCat
2. **到了但是空的** —— 日志出现 `empty_message`。多是你发了图片/表情，转成了空事件
3. **回复为空** —— 日志出现 `The message is empty`。上下文太长，`/reset` 清对话
4. **她说"这个插件连不上"** —— 多半是她凭旧记忆在答，不是真的坏

## 记忆库看起来是空的

程序的记忆存在插件的 `data/memory.json`，她文件夹里的 `记忆/记忆.docx` 只是给人看的副本。
两份都要有，否则她会"以为自己失忆"。

## 拆气泡把链接切断了

别在切句函数里直接用长度切。先把 URL 换成占位符，切完再还原——链接里全是标点，会被当成断句点。

## 她怎么学会说话的

两套并行：

- `self_learning` 插件：采集消息 → 提炼表达模式 → 人格更新（需要关掉"委托给其他插件"的开关，否则它什么都不做）
- 自建语料本：每轮随机注入几条参考说法，**参考不是台词**，照抄会假

## 上下文爆掉之后

单个会话超过几百万字符，模型会开始返回空文本。夜里定时清一次会话，长期记忆不受影响。
