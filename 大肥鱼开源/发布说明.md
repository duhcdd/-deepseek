# 发布步骤（给瑞克）

这个文件夹里就是你说的"她"。下面三步可以发布出去。

## 一、先看一遍，有没有不该给的

打开 `persona/大肥鱼的人设.md`，里面还留着人名「瑞克」和称呼「大肥鱼」。
- 想保留这个味道，就不改；
- 想彻底匿名，把「瑞克」换成「你」，把「大肥鱼」换成随便什么名字。

其他文件里已经没有你的 QQ 号、token、API key（我扫过两遍）。

## 二、发到 GitHub

```powershell
cd "C:\Users\34286\Desktop\大肥鱼开源"
git init
git add .
git commit -m "init: 大肥鱼 —— 一只住在 QQ 里的蓝鲸鱼娘"
git branch -M main
git remote add origin https://github.com/你的用户名/dafeiyu.git
git push -u origin main
```

没有 git 的话，直接在 GitHub 网页上新建仓库 → "uploading an existing file" → 把整个文件夹拖进去。

**仓库名建议**：`dafeiyu` 或 `astrbot-dafeiyu`
**描述建议**：一只住在 QQ 里的蓝鲸鱼娘 —— 人格、记忆、日记、表情包、B 站，全套开源

## 三、要不要带她的脸

72 张表情包不在这个文件夹里（28 MB，而且是二创，你没有转授权）。

想给的话，单独打个包放到 Release：

```
D:\大肥鱼开源包_表情包.zip
```

并在 Release 说明里写清楚来源和授权状态——这个必须说，不然会有人替你担责。
